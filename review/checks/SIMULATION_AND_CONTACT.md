# MATLAB/Simulink、柔性关节与接触检查

## 模型与物理 oracle

按 Issue #2 的定义核对：`delta = theta_m/N - q`，`tau_s = Ks*delta + Ds*(omega_m/N-q_dot)`。电机方程负载项为 `tau_s/N`，负载侧接收 `tau_s`；不得重复折算惯量或损耗。具体方程以本轮契约为准，不因参考论文更复杂而增加范围。

- 核对 kg·m²、rad、s、N·m 的单位与正方向；摩擦、重力、传动阻尼及外力的功率符号一致。
- 以无外力无损耗能量守恒、有阻尼耗散、静态平衡和已知极限工况交叉验证；容差随数值误差说明，不能直接用模型代码产生自己的 expected。
- 传动输出力矩 `tau_s` 与接触力矩 `tau_env` 不相等：负载惯性、重力、摩擦需进入平衡。力与力矩转换必须给几何/Jacobian/力臂，不能混写 N 和 N·m。
- 电机侧反馈基线不可读输出真值；双编码器/力矩反馈只读传感器模型输出。真值用于评价；精确前馈仅限注明的理想对照，正式鲁棒性用名义参数。

## 离散与连续的边界

- 控制周期与积分步长分别记录；电流内环有限带宽、延迟、饱和不能隐式变成瞬时理想力矩源。
- 明确采样、保持、延迟缓冲、更新顺序、首次样本及跨速率传递；不得靠求解器步数代替控制 tick。
- 初始化不依赖残留 base workspace、persistent/global 状态、上次运行的 delay/RNG；从干净会话按记录入口可复现。
- 记录 MATLAB/Simulink/工具箱、编译器、solver、固定/变步长、容差、零交叉设置。步长减小/容差收紧后检查关键指标和失稳判定，保持物理采样周期不变；有限收敛检查不保证所有工况。
- 检查代数环、接触切换和刚性系统对求解器的影响，不用平滑、clipping 或滤除 NaN 来掩盖发散。
- `.slx` 二进制仅凭 git 文本 diff 不足以审查内部变化；需要实际模型检查或可读模型差异/导出证据，缺失则相应路径 PARTIAL。

## 伺服、阻抗与接触

- A/B/C 用相同对象、参考、限制、扰动及记录的调参规则；传感器变化和算法变化分开消融。主动阻尼或陷波先选一种，不擅自堆叠算法。
- 单侧接触定义间隙、法向、穿透与相对速度；接近、压入、保持、回弹、脱离均检查，分离后不产生虚假拉力。阻尼项不得因分离速度产生非物理吸引。
- 控制器增益、输出限制、传感器误差/延迟进入分析。自由运动稳定不推导接触稳定；正刚度和正阻尼本身不证明有采样/延迟/饱和的闭环被动。
- 若声称被动性，写明能量存储、功率端口和假设；时变刚度/参考或模式切换可能注入能量。固定参考的标量势能 `V=0.5*K(t)*e²` 中有 `0.5*K_dot*e²` 项；不能只保留阻尼耗散。增加能量罐等算法需独立范围，不属于本包自动要求。
- 参数/延迟扫描保留失败和边界工况，用更精细数值设置复核边界。结论只限被测区域，不称全局稳定性或真实硬件接触安全证明。

## C 与 MATLAB 对照

- 采用实际版本支持的 C Caller 或 S-Function/MEX 路径，不假设可选工具箱已安装。
- 核对 single/double、采样、输入/输出和状态布局、初始化/终止、饱和与执行顺序；同一输入序列比较输出及关键状态，容差有依据。
- 共享控制核不能夹带寄存器/串口依赖；主机执行同一 C 模块是软件对照，未接 MCU 实时闭环不称 HIL。
