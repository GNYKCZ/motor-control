# Model C开关级第一批证据

run_model_c模拟三桥臂理想MOSFET导通/二极管续流状态、互补死区、浮动中性点三相RL、80kHz差模低通、单独假设共模边沿响应、ADC采样孔径平均和量化。

锁转子、等效各相L=(Ld+Lq)/2，已改为U/V各20mΩ、W无采样电阻的实际两相拓扑；通过中性点约束消元，仅积分两个独立相电流，第三相由KCL恢复。开关为理想状态器件，非晶体管寄生模型；共模耦合幅度为假设，不是由INA199内部电路推导。REF1.65V仍是假设。

24组扫描：0/90/500ns死区，0/12.5/25/37.5us采样相位，0/30mA边沿耦合。25ns离散步长会把90ns非重叠时间向上取整为100ns；此项是模型时间量化，不能称准确90ns仿真。100ns用例的25→12.5ns细化对照检查同一物理死区。

首批通过KCL、等duty零差模、平均相电压与独立理论值比较；平均电压最大差0.00770474V，细化采样真实电流最大差0.490824mA。直通状态检查是实现不变量，不能验证实物栅极直通风险。

ADC aperture为7.5/12MHz=0.625us。sample_t为孔径结束，conversion_complete_t另记录20/12MHz的转换完成；闭环平均模型的775us从有效反馈事件计至施加，不再次叠加同一总延迟。C采用自定义状态方程，不声称Simscape物理器件交叉。新增run_switching_crosscheck在共同锁转子/等电感/无死区子集完成闭环平均/开关对照：40mA工况周期平均差2.413mA，25/12.5ns细化差1.809mA；尚不能把平均模型测量精度等同于含全部模拟瞬态的开关闭环精度。

本文件保留首批记录；最终解释见comparison_report.md。REF名义值来源现已从原理图确认，共模耦合另见ref_root_cause.md；这里固定REF只用于隔离开关/模拟通道的假设效应。

C的载波原点设为峰值（输出低），相位0相当于TIM1从CNT=0起计后的25us；相位25us相当于TIM1的0us高窗。相位扫描是相对载波的比较，不直接把横轴0/25us写成板端绝对触发时刻。Model B独立验证了225/250us的映射。

修正过程中全三状态矩阵指数积分出现累计零序数值漂移，KCL测试失败。已改为物理约束消元的二状态积分，并重新运行全部24组通过；没有放宽KCL容差。
