# O3复杂度与失配筛选

新增run_o3_mismatch，生成对象的恢复常数5/20/60us，候选M3固定20us；另加入候选未包含的二次非线性项。20个种子、训练500点、验证300点、独立测试300点，共120组。

模型先按验证RMSE筛选，0.2mA以内优先简单模型；随后以预先设定的验证集峰值3mA筛选。该阈值来自研究经验目标，不能当作由硬件规格证明的误差界。

120组中47组通过验证集筛选，73组拒绝；本批未出现验证集通过但独立测试峰值超过3mA的情况。匹配M3的20组全部通过。有限留出验证不保证任意未来数据，仍需声明输入域、噪声假设和实测证据等级。

因此O3输出应包含：模型结构、参数、训练/验证条件、误差证据和适用域，不只是一个k常数。模型失配时应拒绝系数导出或提出补充特征/实验，而不是把拟合误差交给PI自行消化。
