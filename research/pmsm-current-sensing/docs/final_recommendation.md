# 最终研究推荐

推荐：**优先核对并修正REF/采样链；剩余误差采用可信零偏标定＋O3离线辨识＋有效域内固定补偿。**

理由不是预设O3一定最好。A1原理图确认无缓冲共用分压，TI明确指出该连接的REF源阻抗影响共模抑制。名义网络预测50%条件下58.25mA，接近历史61.5mA，为一个优先可验证的硬件候选。当前测量仍不足以唯一确认动态机理或选择M1/M2/M3。

仿真证明：匹配模型时O3与可信标定RLS后冻结都能把dq测量误差降至约1.4mA；错模型或温漂仍可造成20–35mA误差；未经门控RLS可吞掉真实40mA；同时未知电压扰动和测量偏置时当前ESO模型不可完全观测。故运行中在线自适应不是当前首选。

数学模型：`m=i+b(x)+n`，`c=m-bhat(x)`。b可为每相duty、共同duty或可观测共模/时序特征；共享REF还提示U/V共模之和特征。模型由独立数据选择，不预认每相k×duty。

最终实物系数：20kHz b0/ku/kv及误差界须实测，当前不导出虚假的认证参数。0.122905A/duty是40kHz近似摘录拟合；parameters.m中的0.123/0.118仅是合成生成器。REF简化网络0.116505A/duty是模型推导，不是板端校准。

适用条件：可信标定、同采样时序、同工作域、可用的模型特征、总测量误差有独立依据。失效条件：越域、温漂、错误模型、ADC饱和、非法/失效标定、过大残差、保护触发。退出补偿应退出动作，不退回未经确认的原始反馈继续控制。

STM32接入必须同时审视先于补偿执行的原始W保护，不能简单删判据。研究候选C已主机验证，尚未集成或MCU验收。硬件快速停机链保持独立。板端参数和保护有效性以独立真实电流验证为最终门槛。

完整证据、结果和边界见comparison_report.md；最小补测见experiment_design.md。研究结论允许物理模型尚未唯一确定，不把缺实物证据伪装成仿真已经解决实际硬件问题。
