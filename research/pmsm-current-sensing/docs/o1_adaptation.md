# O1门控、持续激励与漂移

run_adaptation_stress使用2s数据，前0.5s为合成可信零电流窗口，之后注入40mA真实电流。比较联合b0/k门控RLS、归一化梯度、无门控RLS和已知b0的单参数RLS。

固定duty时联合辨识信息秩不足，门控拒绝更新；已知b0且真实电流已知时，单参数k可以在固定非零duty下估计。不能笼统说固定duty下所有RLS都无法辨识。

交替0.3/0.7 duty时联合门控RLS在这一组固定超参数下约50ms进入并保持50ms的k误差±0.005A/duty范围；梯度法在给定0.5s窗口内未达到同一条件。不得将单次结果推广为所有调参下RLS优于梯度。

无门控RLS可把40mA真实电流吸收到b0估计中，即使k看起来接近正确，补偿后的真实电流误差仍约39mA。因而只看k收敛不够。

可信窗口后冻结可防这种误学，但偏移持续漂移时会留下约6mA级误差。解决该漂移需要新的可信窗口、额外参考或更可靠的物理模型，不能靠恢复无条件更新解决。

当前FOC无在线独立电流参考，因此推荐的运行门控保持冻结，实质为已辨识参数前馈；不把它宣称为完成在线自适应。闭环统一比较中在线RLS不具备有效更新条件，依照此证据暂不启用。
