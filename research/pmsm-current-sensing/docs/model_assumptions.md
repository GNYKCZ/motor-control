# 假设登记

模型A：输入真实U/V可独立指定，是信号链实验台；非等duty与零真实电流的组合只用于隔离算法数学行为，不声称实物电机可实现。真实值仅供生成与评价。标定器仅在显式known_reference条件下获得带噪参考。
REF名义1.65V来自A1原理图的10kΩ/10kΩ共享分压；固定理想REF仍是A/B基线模型假设，不能当成实际恒定电压。REF共模耦合另在run_ref_hypothesis研究。ADC采用0..4095计数、4096分母。基线先以精确已知b0检查链路，512帧估计误差另测。延迟对输入与PWM特征一起作用，评价保留当前时刻与采样时刻两种真值。
M3为可解释行为基函数，不代表INA199内部物理模型：各相占空比*Vbus/12、采样开关状态*Vbus/12、边沿恢复项。恢复常数20us是研究假设，与80kHz差模带宽分开。
合成噪声、漂移、温度系数和参数范围均为假设，置信区间只覆盖该统计模型，不能当作实物不确定度。
