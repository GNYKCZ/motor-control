# 实验矩阵、评价口径与最小实物补证据

## 已执行的软件试验

| 要求 | 工况与证据 |
|---|---|
| 零电流50%duty | run_model_a手算123mA/60°与独立SLX；FOC零参考工况 |
| 30–70%duty | make_design的独立标定/留出；O1常值与交替激励 |
| ADC噪声 | 0、0.8、3mA；种子固定，算法使用同一噪声输入 |
| 采样延迟 | A中0/1/2采样；B施加延迟500/775/950µs；不可混为同一种延迟 |
| 母线变化 | B中10/12/14V，控制核心仍用固件名义12V |
| 固定/漂移偏移 | b0、M1/M2/M3、10mA温漂情形、O1斜率漂移 |
| 真实电流 | A非零波形；B零参考、±40mA、转动与动态转子 |
| 参数变化 | R/L±30%局部线性；B R高/L低/磁链倍增；机械J/B为假设 |
| 异常与饱和 | ADC饱和、无效证书/误差界、越域、持续电压饱和及恢复 |
| 开关时序 | C死区0/90/500ns，4采样相位，独立假设共模瞬态；步长细化 |

主统一矩阵为13情形×9算法×3种子=351。额外120组O3失配、120组ESO对照、16组O1漂移与54组线性分析各回答不同问题，不将它们简单合并成“成功率”。

训练数据1200点、选型数据400点、独立测试600点；同一批生成规律一致时表现好仅证明模型内泛化。O3另改恢复常数和加入非线性，检查失配筛选；没有无限域保证。

## 指标

- dq误差：`sqrt(mean((id_feedback-id_true)^2+(iq_feedback-iq_true)^2))`；只在有效运行区间计算，含采样保持造成的动态误差。
- iq跟踪误差另列；不能用测量误差1.4mA冒充参考跟踪误差1.4mA。
- 提前停止不填零RMSE，保存trip_code和active_duration。运行至期限也不算校准证书通过，另检查独立真值计算的界外次数；该检查仅事后评价，不馈入控制器。
- 参数收敛以连续50ms斜率误差小于0.005A/duty为O1试验定义；不是所有算法通用物理性能指标。固定参数方法无运行中收敛时间，ESO状态误差与带宽另列。
- 稳定性依据包括局部离散极点、实际PI积分有界与恢复、有限闭环工况；不宣称全局稳定。
- 3种子报告范围/均值，不用其构造精度很高的置信结论。LS区间只对应合成独立同分布噪声假设。

## 最小实物补证据（由用户执行，不自动运行）

先核对A1原理图是否匹配实板，特别是REF共用10kΩ分压。使用已批准的供电限流、零矢量诊断和原有停机路径，不因本报告扩大电流、取消保护或自动上电。

1. 同一20kHz配置、两个225/250µs采样相位，各记录0/30/50/70%等占空比。按动作保留全部原始帧，不只末尾平均；每次记录版本/模式、母线、温度、复位/校准状态。每点至少多个独立动作；先确认稳态，再定义平均窗。历史40kHz与此分表。
2. 同步测REF对地与OUT对REF。示波器可检验瞬态与采样窗；万用表只能给平均量，不能据此排除快速瞬态。先看REF变化是否足以解释共同偏移，这是当前信息收益最高的一项。
3. 独立真实相电流参考。PWM相电流应使用带宽/量程已知且连接适合的测量链；普通直流钳表/万用表不能自动作为瞬时真值。无此条件时只确认经验读数和数学一致性，不能证明补偿未掩盖真实电流。
4. 在允许的非等占空比/已知电流试验中改变电压矢量与零序条件，区分du、三相dmean与du+dv/REF模型。只改变一个固定矢量的零序仍可能秩亏；不能假设通电非等占空比下真实电流为零。
5. 留出不同会话、供电和温度记录检验模型；测量参考本身的不确定度计入残差预算。若超域或任何保护/异常出现，按既定停机路径结束，不以算法拟合结果放宽保护。

没有独立电流与动态波形时，允许结论是“REF为有电路依据的优先候选，模型未唯一确定”；缺这些数据不妨碍已完成的名义研究，但阻止认证实物补偿系数。
