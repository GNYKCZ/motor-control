# REF共用分压：优先验证的具体根因候选

## 直接证据

本地A1资料的原理图 `D:/codex/motor/A1资料/原理图/原理图.pdf` 第1页左下角：R12=10kΩ接地，R13=10kΩ接3.3V，中点标1.65V，共接U2/U11 INA199A1的REF。图上没有REF缓冲器。C10/C11=100nF是供电V+去耦，不是REF滤波。U/V各20mΩ，W没有采样电阻。原理图与实板一致性仍须人工核对。

[TI INA199 SBOS469H](https://www.ti.com/lit/ds/symlink/ina199.pdf) 第15页7.4.3明确说明：REF外部阻抗会影响共模抑制；采用电阻分压时需运放缓冲，并给出相对REF差分采样的另一种办法。第3页内部电阻表和第14–15页简图给出约1MΩ的输入至REF路径。此事实使“REF是理想不动的1.65V”不再是可靠硬件假设。

## 可计算且不拟合实测的预测

取分压戴维南电阻 Rt=5kΩ，单器件输入至REF路径近似 Rp=1.02MΩ，两器件共享REF。简化节点方程：

`Vref_node = (1.65/Rt + (Vcm_u+Vcm_v)/Rp) / (1/Rt+2/Rp)`。

相对共模0V基线，`delta_REF = Rt/(Rp+2Rt) * (Vcm_u+Vcm_v)`。由于20mΩ×50=1V/A，该电压偏移数值等于等效安培偏移。**如果**所记录读数反映共模平均量，等duty时名义斜率为0.1165A/duty，50%/70%分别预测58.25/81.55mA，与历史近似61.5/86mA同向同量级。未为匹配这三点调整电阻。

这比随意指定一个0.123A/duty更有物理根据，但还不是实际PWM采样偏移的预测：该节点的寄生电容、器件内部动态、输入电流的共模依赖、ADC具体孔径与相位均未测量。不能把PWM时间平均与同步瞬时采样混为一谈。0.1165和0.123接近不构成因果确认。

反算0.123A/duty对应约0.966MΩ路径，只是等效参数，不是测得电阻。假设路径±30%的敏感性在ref_sensitivity.csv记录，不作为置信区间。假设将参考源阻抗降至1Ω，则这条简化耦合路径的斜率降至约23.5µA/duty；不承诺实际换缓冲器后达到该精度。

这个共享网络预测偏移与U/V共模之和相关，未必等于三相dmean模型。后续候选特征应包含du+dv/REF实测值；非等占空比时不能预认M1或M2。

## 改变后的优先顺序

1. 人工核对板卡是否确实按此无缓冲分压装配。
2. 在既有获准诊断条件下，独立记录REF对地及INA输出对REF的变化；优先比较225/250µs两个窗口。有示波器时记录完整同步波形，没有时万用表只支持平均变化的证据。
3. 若REF确实随PWM改变，优先设计低输出阻抗REF缓冲，或有同步测量与误差预算支持的OUT−REF采样方案。运放的供电/输入输出范围、负载稳定性与布线须验证；此处不直接选型或改板。
4. 修改前后在相同工况、独立电流参考下比较残差。若主要偏移消失，可简化为开机零偏+剩余误差校准；若仍有动态偏移，再做O3特征辨识。观测器不能代替修复已确认的模拟参考问题。

因此当前最终候选应是“先核实并修正REF/采样链，再对剩余偏移离线辨识和固定补偿”。仅软件方案仍可作为条件性研究方案，禁止把未经验证的经验k直接写入保护链。
