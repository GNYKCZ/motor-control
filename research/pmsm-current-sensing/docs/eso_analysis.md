# ESO方程与适用性

Ts=1ms，a=exp(-R*Ts/L)，g=(1-a)/R。

测量偏置ESO：x=[i,b]，A=diag(a,1)，B=[g,0]'，y=[1,1]x。
真实电压扰动ESO：x=[i,dv]，A=[a,g;0,1]，B=[g,0]'，y=[1,0]x。
采用离散预测器xhat(k+1)=A*xhat(k)+B*v(k)+K*(y(k)-C*xhat(k))。
极点放置为exp(-2*pi*f*Ts*[1,1.2])，f扫描5/20/80/200Hz。宽带可能放大测量噪声，低带宽对快电气对象的初值/扰动响应也可能很差；不因极点在单位圆内就宣布电流估计准确或整体闭环稳定。

同时把真实电压扰动和测量偏置扩张成三个状态时，A=[a,g,0;0,1,0;0,0,1]，C=[1,0,1]。可观测矩阵秩为2；[1,R,-1]'为特征值1的不可观测方向。实际电流、真实电压扰动和测量偏置可以沿此方向变化而输出不变。

120组对照已记录于eso_comparison.csv，数据包含慢/快偏移、物理电压扰动、两者同时存在和R偏差，三个噪声等级、四带宽、两ESO。独立真值仅用于评价。扩张状态指标单位随模型为A或V，不允许跨两种模型直接排名；电流RMSE均为A可比较。

当前结果支持：O2需要额外可观测性假设，不应作为未知电压与未知采样误差同时存在时的自动消偏器。测量偏置ESO现已进入273组闭环压力集；当前冷启动配置在有偏移时不能满足候选保护条件，不能作为即插即用的补偿替代。这不否定其他初始化、额外测量或不同设计的ESO。完整选型边界见selection_decision.md。
