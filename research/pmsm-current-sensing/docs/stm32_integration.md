# STM32移植建议与候选接口

此研究不修改生产固件。`c/bias_compensation.h/.c`是可移植研究候选，已在Windows主机编译；未执行MCU目标构建、时延测量、烧录或电机运行。它不应直接替换现有保护。

## 数据流与时序

1. PWM关闭且真实电流已衰减的可信窗口，保留512帧标定及方差/连续性检查。计数原始基线、名义电流偏差必须统一单位，不能重复减b0。
2. ADC帧绑定当时真正施加的U/V/W占空比、采样相位和版本配置；不能用待提交的下一拍duty。沿用现有generation/applied确认机制，旧帧/错序不得补偿。
3. 校准对象包含b0、k、模型编号、误差范围、适用duty/母线/温度/采样相位、来源与校验标识；当前无已验证20kHz参数，启动状态必须为未认证。M3另需特征计算和母线/相位信息，本候选不支持，明确拒绝模型3。
4. 先检查ADC饱和、帧有效性、校准有效域，再计算修正UV/W及电流区间。输出permitted为false时退出动作，不能继续使用未经确认的修正反馈。真实快速故障/停机链独立保留。
5. 经评审的板级接入才可把区间判据放到原始W保护对应位置；否则现有runtime会先停机，后置current_loop补偿无效。任何接入均需重新跑保护、ADC异常、时序、模式与控制回归并更新固件版本。

## 候选C接口

`bias_compensate(cal,input,output)`不分配内存、无静态可变状态；M1/M2每帧仅两条线性表达式、三个上界与有限性/有效域检查，无迭代矩阵。内存为输入、配置和输出结构体；在STM32上实际尺寸/周期需目标编译和测量，不用主机速度推断中断预算。

校准b0单位A，k单位A/duty；输入ADC为整数0..4095，占空比0..1，母线V。函数以1.65V名义参考换算；b0含相对该名义参考的全部固定偏差。当前硬件常量20mΩ、增益50、3.3V/12bit均写明；更换硬件常量必须一起重验。

每相总模拟误差界epsilon需覆盖偏置残差、噪声、增益等；C另加半LSB和2µA浮点余量，W加两相总余量。保护阈值仍为128个名义ADC计数，不变更为额定电流。浮点运算输入参数受限；禁止fast-math。

无效校准、unsupported model、NaN、非法误差界、饱和、越域及区间越限返回不同原因。函数仅说明该**假设误差契约**下的数学判断，不能验证调用者声称的误差界是否真实。

`python c/test_bias_compensation.py`构建并检查5万组M1/M2与独立双精度公式的误差、阈值决策及非法输入。当前上界计算差约0.15µA；采用正余量避免数值舍入将边界向内缩。有限随机测试不是全域硬件保证，区间包含关系来自三角不等式。

## 不直接给实物k的原因

历史40kHz的约0.123A/duty不是20kHz校准值；等占空比不能区分每相、共同参考及动态模型。REF原理图又提示共享参考耦合。`fit_parameters.csv`与O1拟合系数均来自合成信号，禁止复制为实物认证参数。最终参数表中实物k及误差界保持TBD，这是证据结论，不是漏交。

在当前硬件条件下，首选核实REF源阻抗；若缓冲修正能消除主要误差，应重新标定剩余误差，而不是继续保留旧经验补偿。
