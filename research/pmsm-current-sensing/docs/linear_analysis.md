# 固件对应的局部线性电流环

run_linear_analysis使用实际Kp=0.5、Ki=150、Ts=1ms，名义R/L；以采样完成为时间原点，施加电压延迟tau后改变。禁止将计算周期与数值步长混淆。

定义a=exp(-RT/L)、b=exp(-R(T-tau)/L)、g1=(b-a)/R、g2=(1-b)/R。状态为采样电流、PI旧积分、上一施加电压。未饱和闭环矩阵：

```
A = [a-g2*Kp, g2, g1;
     -Ki*T,   1,  0;
     -Kp,     1,  0]
B = [g2*Kp; Ki*T; Kp]
```

名义775us提交延迟：d轴带宽4.1702Hz、q轴4.2004Hz，谱半径约0.9743，直流增益1。带宽由闭环频响第一次下降至1/sqrt(2)的离散频率网格确定，非实测。R/L各0.7/1/1.3倍、延迟0.5/0.775/0.95ms共54组局部扫描均位于单位圆内。

这不是全局稳定证明：未包含保护停止、饱和、时变补偿、偏移动态、量化极限环、机械速度耦合。不得用此结论覆盖那些工况。名义R/L来自用户参考值，不是2208实测标定。

Issue2接口初步可用该有限带宽作为名义电气近似，但正式接口仍需非线性与时域交叉和完整转矩换算说明。
