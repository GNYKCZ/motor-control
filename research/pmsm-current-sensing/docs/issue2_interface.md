# Issue #2 电气驱动接口

关联目标：[柔性关节双编码器伺服与接触阻抗研究](https://github.com/GNYKCZ/motor-control/issues/2)。本交付只负责电气电流内环，不复制双惯量、减速器或接触环境。

## 两个复用层级

1. `issue2_drive_step.m` / `issue2_drive_sfun.m` / `models/issue2_drive_demo.slx`：低速q轴降阶内环。包含实际名义PI参数、分段保持延迟、参考限幅、0.4V电压限幅、抗积分饱和、反馈残差和等效量化。适合先搭建关节外环。
2. `pmsm_foc_model.slx`：完整dq电气方程、实际C控制核心和两相ADC。需要研究转速耦合、角度、偏移保护或电压饱和细节时使用此层。其机械对象是示范模块，接入Issue2时机械状态应由Issue2提供，避免再积分一份电机惯量。

## 降阶接口契约

每1ms调用一次。输入向量为 `[iq_ref_A; omega_m_rad_s; feedback_residual_A]`。机械速度在电机轴侧；电角速度=7×机械速度。第三项为校准残差/噪声的显式实验输入，不能从真实未知电流反推后提供给控制器。

输出 `[iq_true_A; iq_feedback_A; torque_true_Nm; torque_feedback_Nm; voltage_saturated]`。真实iq/转矩供物理对象及评估；外环只能使用其真实传感配置允许的反馈。estimated torque不能代替输出侧传动力矩或环境接触力矩。

状态 `[iq_A; integral_V; previous_voltage_V]`；初值零。电机名义参数R=5.5Ω，Lq=0.905mH，磁链0.00257Wb。采用上一电压持续775µs、当拍电压持续225µs的精确RL离散化；**不要另加一次775µs延迟块**。量化是q轴等效近似，不等价于所有转子角下的实际两相ADC量化。

| 量 | 交付值 | 证据性质 |
|---|---:|---|
| 电流环周期 | 1ms | 固件配置 |
| 施加延迟 | 775µs | 740–810µs软件验收窗中点，非板端实测 |
| 局部d/q带宽 | 4.1702/4.2004Hz | 名义线性化−3dB，不是实测 |
| 相ADC量化 | 0.805664mA/count | 名义3.3V、20mΩ、增益50 |
| 噪声 | 0/0.8/3mA每相标准差 | 合成工况，不是传感器实测规格 |
| iq参考限幅 | ±40mA | 现有固件实验限幅，不是1.5A额定工况 |
| dq电压限幅 | 0.4V | 12V与固件调制限值 |
| Kt | 0.026985Nm/A | 1.5×7×0.00257，名义参数推导 |
| ±40mA对应转矩 | ±0.0010794Nm | 仅名义电磁转矩、id=0 |

完整转矩为 `1.5*p*(psi*iq+(Ld-Lq)*id*iq)`。Issue2在机械侧处理传动比、摩擦和负载，不能再次把输入iq或Kt乘减速比后又折算一遍。

## 适用范围和实测替换

降阶模型是低速、id近零的局部近似，未模拟d轴耦合和完整故障状态机。速度反馈只加入名义反电动势项。较高转速、长时间电压饱和、大d轴电流或保护判据研究应切换完整模型。外环稳定性须针对真实的有限带宽与延迟分析，不能将其当理想瞬时力矩源。

误差输入可做固定偏移、漂移、噪声序列。真实零参考时反馈趋零并不能证明真实iq零：示范输入2mA残差，20mA参考的稳态真实iq约18mA。这一行为专门保留以显示测量误差向转矩传递。

`run_issue2_interface`实际生成并运行SLX，和独立逐步执行完全一致；无量化时与解析3状态离散方程差约1.39e-16。测试记录在issue2_interface.csv/mat，曲线issue2_interface.png。此证据不包含实际关节稳定性或板端验证。
