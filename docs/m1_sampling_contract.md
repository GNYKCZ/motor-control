# M1 采样基线：实施前固定的范围与验收

设计：Issue #7 v1.1，第 8、9、12 节；Refs #1。起始 main 为
`b4de4abd03d46ee88897db950447290a5e6fd8b6`。本批仅为 P0a，不包含电流闭环、运动模式和硬件运行。

## 用户确认的输出边界

在本次 M1 交接中用户确认：“接受软件基线，功率关断单列缺口”。
本地 V2.0 原理图中 U4 的 EN1–3、nSLEEP、nRESET 固定接 8313_3.3V，
MCU PA8/9/10 仅连接 IN1/2/3。软件永久禁止 TIM1 通道和 MOE，并把三路 IN 保持低电平；
这只能声明“禁止 PWM 调制”。按 DRV8313 真值表，低 IN 且高 EN 是低侧导通的制动，
不是高阻断能。板上可能使用 MS8313，实物型号、上电瞬态和实际电气效果均待核实。
因此功率桥关断验收未满足，不以 duty=0、HAL 停止或主机测试代替。

## 本批文件与来源决策

- `firmware/stm32f103/Core/`：自编最小入口和中断路由；保留 Cube/MDK 目录习惯。
- `board/board_io.[ch]`：自编引脚、HAL 初始化、原始 ADC/DMA、计时及串口适配。
- `board/sample_frame.[ch]`：自编 MT6701 协议验证、完整采样包和时间边界，供主机测试使用。
- `board/board_config.h`：本批唯一硬件/时间参数来源。
- `app/motor_runtime.[ch]`：只实现 BOOT、DISABLED、FAULT，永无 RUNNING/对齐入口。
- `app/telemetry.[ch]`：前台格式化，串口中断逐字节发送；忙时跳过状态且计数。
- `Drivers/`、启动文件：仅引入具组件许可的必要 ST HAL/CMSIS 文件，逐文件记录 SHA256。
- `MDK-ARM/`、`tools/`：ARM Compiler 6.13.1、O2、64 KiB Flash / 20 KiB RAM，真实构建与测试入口。
- `tests/`：帧完成、CRC、时间、生命周期、快照、串口拥塞的独立断言。

主要参考快照：`stm32_foc_2`，commit `672e32f1005d9019140d1a9c754fb8ca2e8eedde`。
本地 MDK 工程存在既有修改，不能声称整个参考工作区干净。基础例程无 `.git` 元数据。
作者自定义 FOC、filter、Core USER CODE、原 `.ioc` 与原 MDK 工程文件不复制，
其根级许可尚未明确。自编适配依据外设文档、协议及已核对的板卡连接，不另写控制算法。
不引入本批未调用的 DSP 二进制库/控制核。

## 验收矩阵（实施前 oracle）

| 条目 | 独立依据 | 工况/观察 | 方式 |
|---|---|---|---|
| A06 软件门控 | 仅 BOOT/DISABLED/FAULT；不存在使能路径 | 上电、初始化失败、空样本、无效/陈旧样本、故障后正常样本仍 FAULT | 主机调用真实 runtime，断言状态和 board 禁止调用；寄存器配置核对 |
| A07 完整帧 | 只在 DMA TC 且 3 字节收齐后发布；ADC 双完成后一次发布 | 半帧、CRC 单 bit 错、磁场异常、重复/倒序、超期、模回绕、交错读写 | 协议多项式长除法 oracle + 真模块测试；IRQ 临界区前后状态断言 |
| A09 构建 | 全部源码/库路径在仓库内；C8 标称容量 | ARM 6.13.1 O2，真实 axf/map；复制已列依赖到独立干净目录再构建 | 构建入口、警告、Flash/RAM、栈预算、文件清单/哈希 |
| A10 状态 | 设备整数时间、采样/编码器序号；串口忙不覆盖缓冲 | 已知帧序列、发送忙/断连、时间回绕 | 前台导出格式断言；高频路径无打印/阻塞发送 |
| A12 阅读 | 完整英文、单位、中文职责/参数/状态/边界注释 | 所有自编文件和接口 | 人工逐项核对 + README 真实调用链 |
| 电气关断/真实采样/耗时 | 板卡实测 | 按用户另行安排的供电、限流与观察方案 | NOT RUN；功率高阻关断能力另为未满足项 |

没有板端数据时，不宣称反馈正确、电流已校准、实时预算已满足。首次编码器尚未完成的 ADC 包
可发布但标无效；运行管理仍保持 DISABLED 等待首个有效帧。收到过有效帧后出现异常则锁存 FAULT。
不自动清故障，也不增加串口使能命令。时间为 1 MHz、32 bit 微秒；差值按无符号模运算，
合法最大间隔远小于半周期（2^31 us）。角度时间记录读取开始/完成区间，不能伪称传感器采样时刻。
