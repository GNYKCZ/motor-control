# M2c：仅采样现场验收步骤（尚未执行）

这是待单独安排的现场任务，不是烧录/上电授权。用户能安排板卡、电机、下载/串口与供电，
没有示波器。本批只交付步骤和软件；每次实际操作前仍需明确安排板卡/供电/固件和现场操作人。
不能从串口日志推断PWM波形、死区、复位瞬态或功率桥高阻关断。

## 现场前提与停止点

1. 核对实际板卡版本、U4装配、电源输入额定值及电源/下载器/串口针脚，拍照记录。确认本板
   主输入确为12V且与现有V2原理图一致后，以下12V步骤才适用；不一致时停止并回设计。
2. 电机三根相线与功率桥物理断开并分别绝缘，电机/编码器固定好；不要短接相线。
   零偏候选要求静止且无相电流。三路IN低是低侧制动语义，不是桥高阻保证。
3. 单一电源供电。核对下载器3.3V端是检测还是供电输出，避免与板电源并联；不清楚时停下。
   串口使用3.3V逻辑，板PA2 TX→适配器RX、共地，不接5V/RS232电平；不需要给板发命令。
4. 断电接线，限流电源先设12.0V、0.10A作为“电机断开、只运行板上逻辑”的诊断起点。
   未经确认板卡额定输入前不得照此供电。进入限流、供电异常、发热/异味或板复位时立即断电；
   不通过自行提高限流继续测试。停机路径是现场可直接操作的电源输出关闭/物理断电。

## 固件与数据准备

记录被审完整commit、目标HEX SHA256、板卡/电机、下载器、串口号、电源电压与限流、
连接照片和操作人。先在电脑完成目标构建/主机回归，再核对实际待下载HEX哈希。
只有该次现场明确安排烧录/上电后，才用下载器将这一HEX写入；不用IDE自动运行/自动升级另一版本。

串口保存入口（现场替换COM端口、完整SHA和记录；不要照抄示例成真实元数据）：

```powershell
python -m pip install pyserial==3.5
python tools/sensor_capture.py --port COM3 --kind unverified_capture --seconds 10 --output build/captures/site_run_01 --firmware-sha <完整40位SHA> --board <实际板卡版本> --motor <电机型号且相线断开> --supply '12.0V,0.10A,current-limited,motor-disconnected'
```

脚本不发控制字符，但打开串口仍可能影响具体适配器的控制线；本工具已在打开前将DTR/RTS设低。
不清楚适配器连接时先核实。输出目录必须不存在，Ctrl+C停止接收但不能代替板卡断电。

无需板卡的合成示例（已明确不是实测；零SHA仅为合成元数据）：

```powershell
python tools/sensor_capture.py --input tests/m1/synthetic_m2c.txt --kind synthetic --output build/captures/synthetic_example --firmware-sha 0000000000000000000000000000000000000000 --board synthetic --motor synthetic --supply none
```

## 仅采样操作与验收

1. 确认电源可随手关闭、电机相线断开。按本次已明确安排的方式烧录/供电，观察电源电压/电流，
   先保存10秒静止数据，不发任何使能/对齐/电流命令。
2. 期望M2C1、s=1、f=0、pwm=blocked、power=unverified；cn收齐512、cd=1、ca=0、cv始终0。
   观察u/v、min/max与候选均值是否远离0/4095撞轨，是否明显漂移；这只形成候选，不能将cv改为1。
3. cn完成后mv可为1，iu_mA/iv_mA应与raw和候选/名义系数自洽，但没有外部电流基准，不能验收真实A精度。
   静止候选的可用范围/噪声阈值要基于保存的原始分布再定，本批不凭任意阈值自动通过校准。
4. 如需要角度观察，仍保持相线物理断开，只在现场另行明确安排后手动缓慢转动编码器/轴，
   保存a和ma_mrad的单圈变化及16383→0；不做通电转动，不把此方向认定为电角度换相方向。
5. 任何f非0、s=2、ca=1、持续mv=0、raw撞轨、意外复位/运动、限流/异常电流、发热或接线变化，
   立即关闭电源输出并停止。保留完整raw.bin、records.jsonl、metadata.json，不删除失败段，不重启凑齐512。
6. 测试结束先断电，再拆线。将原始记录连同固件/硬件/供电条件交Design复核；不要只发截屏或“看起来正常”。

日志保存包含未知/坏/半行；ok是采样包标志，UART行无额外CRC。仅据现有设备可报告串口字段、
故障状态和供电观察；输出真实波形、时序预算、校准精度、功率关断与实物闭环仍未验收。
