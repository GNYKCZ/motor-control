# 编码器方向、极对数与电零位：受限步进磁场方案

Refs [Issue #1](https://github.com/GNYKCZ/motor-control/issues/1)，属于同一电流与换相标定工作包/PR25。
本页是单独设计审查对象，不是已实现/已烧录的扫描固件。当前可执行固件仍为V相20ms实验。
用户已允许按相对起点最多90°设计，正反方向分次按键确认，实际运行前再确认；
最新同意进入后续标定，不从此推断更长持续激励已实际运行或已获实机授权。

## 阶段成果与前置

目标是从已知定子磁场角与独立编码器机械角的对应关系，得到唯一候选极对数p、编码器方向d和电零位z，
用于 `theta_e = wrap(d*p*theta_m + z)`；单位rad，d为+1或−1，theta_m为编码器原始正方向机械角。
alpha与PWM U相同向，正电角度alpha→beta，遵循control_core/foc_math.h的幅值不变Clarke/Park约定。
这不是电流/速度/位置闭环；不使用未知电角度闭环来证明自己的电角度标定。

已有用户证据：三批静止零偏均值重复性；U固定矢量U↑V↓，V固定矢量V↑U↓。
U动作正常到期，V动作因46count位移保护提前结束；V本次9帧无溢出，开门8185us，
扣本次零偏U−7.203559028/V+16.310112847count，首尾采样角变化+50count。
这些支持两个独立电压矢量下符号响应，不能证明绝对增益、模拟建立、实际峰值或全部相序。
详见[current_angle_calibration.md](current_angle_calibration.md)；用户V摘录保留本地build/current_angle/user_v_response_20261030。

## 具体动作提案

不拆接线，不要求新增仪器。供电仍为用户的普通12V适配器、USB/DAP；没有外部可设置限流的证明。
幅值沿用已测最大比较值60，TIM1 PSC9/ARR1799，PWM约2kHz，ADC约1kHz；不恢复20kHz。
每次启动只允许一次完整PA12按下/释放手势；上电/Reset/串口均不能启动。
先仅提供正向编译版本；反向为另一明确标识的编译版本、另一次用户确认，不自动接着反转。
不提供串口ARM/PULSE、任意角度/幅值/时长或自动加大激励入口。

正向七个保持点，括号为(U,V,W)比较值：

| 点 | 命令电角度 | 固定比较值 |
|---|---:|---|
| 0 | 0° | (60,0,0) |
| 1 | 60° | (60,60,0) |
| 2 | 120° | (0,60,0) |
| 3 | 180° | (0,60,60) |
| 4 | 240° | (0,0,60) |
| 5 | 300° | (60,0,60) |
| 6 | 360°，等价0° | (60,0,0) |

各点200ms，前150ms用于响应，最后50ms记录稳定窗口；总保持1400ms。
接受按键释放起绝对期限1420ms，包含启动/自然更新等待；时间不足就失败，不延长、补点或重试。
后续点以实际自然UEV提交时标为生效依据；各点提交偏差上限2ms，超时撤销。
全程最迟绝对截止不因晚提交、查询、新样本而后移。反向依次为0,300,240,180,120,60,0°。
最后点完成就禁止调制，先停再在主机分析；不保持最后姿态等串口查询。

商家p=7仅作行程规划：一电周预计51.43°机械角，初始找平衡位置最多半电周预计25.71°，合计77.14°。
不是实际p已确认，也不保证能跟随或实际运动不超调。采用相对本次释放起点4000count≈87.89°撤销阈值，
给90°设计包络留约2.11°名义余量；1kHz离散观测、惯性/IRQ延迟仍不能保证物理角度绝不超过90°。
任何点未稳定、无足够数据或越界均失败停机；不因不动而增幅、加时或扩大范围。

这是相对旧实验的重要变化：最长激励由20ms变为1420ms，并将单脉冲改为七点磁场序列。
此处只是可审查提案；较长持续激励与具体现场动作须向用户说明并确认，不能沿用旧20ms运行许可。

## 电流、零偏与时序边界

每启动必须在本次12V供电、转子静止条件显式重开并收齐512帧零偏，无中止/故障；
动作前当前采样/反馈新鲜有效并静止250ms。零偏只用于诊断，不硬编码历史均值，不标绝对电流已校准。
所有比较值在0..60，各矢量仅置换已测幅值或等效反向矢量；不把占空比60/1799称60V或60%。
仍是EN固定高的驱动，MOE0/GPIO低只停止调制，不是功率桥高阻断能。

名义星形8.25Ω/1.08mH模型下稳态峰值约177.8mA，而250us相位测的是关断衰减段。
用户观测的U/V平均名义电流不能当真实峰值或独立限流验证；持续1.4s也不能沿用20ms能量结论。
模型只能用于量级估算，实际绕组、电压、增益与动态均未独立测量，不能用额定1.5A直接宣称实验安全。
拟加诊断撤销：任一通道原始值距本启动零偏超过256count（名义约206mA采样值）立即停；
ADC饱和/无效、驱动nFAULT/BKIN、丢帧、反馈积压、STOP、UART错误和原始/反馈超时也先停并锁存。
256count不是峰值限制，不在本批宣称它覆盖开关尖峰或放大器失真；真实模拟建立仍未测。

SSI200us、ADC250us、已有7.5cycle采样配置保持。IRQ只做整数/有界数组操作，不格式化/浮点/等待。
保持RV-001的“SSI实际开始严格晚于开门”判据；每个保持点也只收实际提交之后的完整帧。
每窗口至少40帧、最多64帧，记录数、连续机械计数和、min/max；角度回绕用已有14bit最短差累积。
稳定窗口角跨度小于16count才合格；缺点/溢出/间断/时间不一致不能用其他点补齐。

## 架构与更新事务

沿用board作为PWM/引脚唯一所有者、runtime作为生命周期唯一所有者；不从数学核直接写寄存器。
专用标定模式拥有七点状态，不全局删除旧短脉冲的46count限制或改变普通profile语义。
新模式按编译期明确标识，与历史U/V短脉冲版本区分；旧短脉冲源与证据保留。
runtime在有效ADC事件中推进有界状态，反馈前台继续运行；主循环卡住时反馈超时仍独立撤销。
独立TIM3每次安排原始/反馈、点提交或总期限中的最早者，不依赖格式化或串口接收来截止。

板级更新走三路CCR预装，不逐相HAL启动、不用UG/UDIS、不从关闭状态重开MOE。
只允许固定表内的点与匹配代次；校验当前模式、故障、总期限和TIM2相位。
按当前250us ADC相位，在远离下一自然更新的位置写三路影子值，再由下一自然UEV提交确认；
没有确认就不能把请求点当已施加点，也不能开始该点的统计。
三路写之间遇到UEV、Break、STOP、取消/新代次、迟到等交错必须撤销或标失败；不能假设三次寄存器写天然原子。
任何可能的中间组合仍限制每路0..60；这只是幅值约束，不把错误相位或混合提交当有效实验。
具体相位边界、写入/确认状态、优先级与编译产物需在实现审查时核实，不能用本设计当已验证。

串口复用固定请求/CRC/序号，STATUS/STOP保持；新增版本化只读扫描汇总，停机后一次查询返回七点和结束原因。
不连续刷大量轨迹。一个查询应含编译方向、配置身份、动作编号、原点、七点有效性/角度统计及实际起止时标。
最终布局/长度/CRC黄金向量与实现同批冻结；串口回执本身不启动或自动接受标定。

## 参数判定与失败规则

机械角度用连续计数转换为rad，命令电角度为k*pi/3（反向取负）。
完整一电周的机械变化Delta_m首先给出候选p≈2*pi/abs(Delta_m)，不用商家7直接填结果。
在整数p=1..32范围要求唯一候选：一周机械位移与2*pi/p偏差不超过5%，各点按命令方向一致前进，
各点机械→电角拟合的最大环形残差不超过15°电角。候选不唯一、无位移、反复跨齿或缺点均失败。
这些是实验一致性门限，不是外部角度精度保证；不根据实测失败偷偷放宽门限。
编码器映射方向d=sign(命令电角增量*机械角增量)，正反两次必须给出同一个d及同一个p。
零位z用各保持点 `wrap(phi_k - d*p*theta_mk)` 的圆均值，正反结果环形差不超过15°电角；
不能用最后一帧或默认零位掩盖各点不一致，不把电压矢量角直接当实际电流或转子磁场真值。
静摩擦、齿槽、绕组差异会造成对齐偏差；只有现有编码器，结论限重复性与配置下的一致性。

正反两次通过后，才形成有来源/版本/单位/有效性的参数候选（两路零偏、名义比例、映射d/p/z）。
本阶段不写Flash、不自动接电流闭环；重启需显式重校或由后续受审应用步骤加载已核对参数。
单方向结果只能候选，不能标完整换相标定通过；p/方向/零位任一失败，不静默回退商家默认值。

## 必要验证和停止点

| 验收 | 独立依据/工况 | 必要证据 |
|---|---|---|
| 七矢量/方向 | 手算Clarke 0,60..360°，反向顺序 | 主机固定表oracle，非复制实现expected |
| 运动/期限 | ±4000count、1420ms、回绕/迟到/缺点 | 生产模式主机注入，旧短脉冲保护不回归 |
| 预装事务 | CCR混写与UEV/Break/STOP每访问点交错 | 真实board模型、错误提交负对照，代次不重开 |
| 数据窗口 | 应用时标后/150..200ms、39/40/64/65帧、16count | 计数/和/极值手算、坏帧不补齐 |
| d/p/z | 合成p7及非7、正反、零位/机械角回绕、噪声、卡住/缺点/歧义 | 独立几何轨迹和圆残差oracle |
| 构建 | .ioc不变的依赖核对、实际ARM/Keil与警告/大小 | 新SHA和输入哈希，未变证据明确复用 |
| 实机 | 用户另行安排、先正后反分次确认 | 两方向原始汇总、故障/位置与名义电流；无仪器不声称绝对精度 |
