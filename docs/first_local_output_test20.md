# 20ms低频测试配置

用户明确要求“4ms扩到20ms，其他也更从容一点，主要是测试”。本配置取代
[首次4ms配置](first_local_output.md)中的频率、期限与新鲜度参数，不代表闭环控制基线。
原按键一次尝试/启动、串口禁止ARM/PULSE、STOP、BKIN、故障锁存与46count位移撤销保持。
不自动烧录、接电或运行；新版本板端验收NOT RUN。

| 项目 | 原配置 | 当前测试配置 |
|---|---:|---:|
| CPU / TIM1输入 | 72MHz | 72MHz |
| TIM1 PSC / ARR / RCR | 0 / 1799 / 3 | 9 / 1799 / 3 |
| TIM1计数频率 / 单tick | 72MHz / 13.889ns | 7.2MHz / 138.889ns |
| 完整PWM周期 / 频率 | 49.972us / 20.011kHz | 499.722us / 2.001kHz |
| 更新触发的原始采样间隔 | 99.944us | 999.444us |
| 反馈每10帧 / 正常间隔 | 约1ms | 约10ms |
| 原始 / 反馈新鲜度上限 | 300us / 3000us | 3000us / 30000us |
| 首帧启动宽限 | 1000us | 10000us |
| 内部ARM事务watchdog | 1000us | 5000us |
| 从接受释放起的动作期限 | 4000us | 20000us |
| TIM2编码器启动比较值 | 50us | 950us |

TIM1以`f_CNT=f_TIM/(PSC+1)`计数，PWM完整周期`2*ARR/f_CNT`。
TIM2/3/4仍PSC71，即1MHz，设备时间戳与截止时钟仍每计数1us。
选PSC9而不把ARR放大，避免改变比较计数的几何关系；两种方法都能放慢PWM周期。
三相tick仍(60,0,0)，margin434、CC4=495、上数允许范围494<CNT<1365不变；
比较事件到上限的870tick实际变成120.833us，而不是原12.083us。
RCR3的更新事件间隔为两个完整PWM周期；原始/反馈频率相应降低，不能继续声称10kHz/1kHz。

## 编码器相位与保护边界

TIM2由TIM1更新事件复位。若仍在复位后50us读取编码器，下一个约999.444us ADC采样到来时，
读取开始年龄约949us，会超过200us有效性上限。本配置把SSI启动移到950us，
到下一次ADC触发约49.444us；名义24bit/1.125MHz传输约21.333us，剩余约28us供完成发布。
200us读取年龄上限、40us传输上限不扩大，因为编码器传输速度未改变。真实延迟仍待板端记录。
首帧可能没有对应的新编码器数据，10ms启动宽限允许建立有效原始流；不清除已锁存故障。

反馈9点窗口在当前配置正常覆盖约80ms，静止资格仍250ms；需等待反馈暖机后才能尝试。
位移检查现在每约1ms观测一次，时间分辨率下降，不能称物理最大转角或更快保护。
断流容许时间变长是用户授权的调试取舍，不能把测试配置的保护延迟继承为闭环验收。
20ms包含资格检查和STARTING等待，不在开MOE时重算，也不因新采样/STATUS续期。

## 名义RL计算与限制

占空比仍60/1799≈3.33519%，但每周期高脉冲由1.667us变为16.667us。
`T=2*1799*10/72MHz; ton=2*60*10/72MHz; tau=L/R`，
`Iavg=V*(60/1799)/R; Ipk=(V/R)*(1-exp(-ton/tau))/(1-exp(-T/tau))`。

| 模型或例示敏感性 | 平均值 | 周期稳态峰值 |
|---|---:|---:|
| 12V、8.25Ω、1.08mH星形近似 | 48.5118mA | 177.7905mA |
| 12V、标量5.5Ω、0.72mH | 72.7677mA | 266.6858mA |
| 例示13.2V、4.4Ω、0.576mH | 100.0556mA | 366.6930mA |

这些不是实测值、真实容差或电流上界。PWM降低后峰值估算升高；20ms也增加本次激励时长，
不能沿用旧58mA峰值或宣称能量不变。无实际电流标定/独立限流证明；20ms仍不保证肉眼可见运动。
EN固定高，禁止调制仍不是高阻断能。无响应不得自动增加幅值或重复尝试。

## 软件验证与后续现场

CubeMX6.12.0实际生成TIM1 PSC9与TIM2 Pulse950。生产门控测试以1ms输入节奏完成按键，
正常输出路径在20ms期限结束；19999/20000us边界、3ms/3001us原始断流与独立TIM3撤销均验证。
推进计数器模型将每个TIM1 tick折算为10个72MHz周期；压力参数仍是测试输入，非实测WCET。
保留短Break/排队STOP/残留IRQ/期限跨越/一次尝试/CRC/UART及旧错负对照。
旧RV-001夹具仅把断流门限对齐3ms，并改用ARM保持状态避免1ms合成脉冲提前到期；
它的补救STOP行为不改，仍须旧夹具通过、修复夹具对注入缺陷失败，不能洗掉失败证据。

软件审查后向用户交付确切HEX。现场先12V断开下载，退出调试；用户明确安排12V、Reset后
等待至少1秒，STATUS序号1确认无故障/id0，再一次完整PA12手势，等待1秒，STATUS序号2保存回执。
只用完整HEX帧一次发送，关闭自动发送；此后不Reset/重复按键，不因不动扩大参数。
正常预期动作1、开始和结束时标均有效、why=C4、最终s1/f0；故障则保留真实回执。
动作时标是MCU记录而非外部电气波形，截止附近IRQ延迟不能伪称精确20000us电气边沿。
新版本未实测；此前0x44失败事实保留在历史文档，不能把放慢配置写成根因已证实修复。
