# Motor Control

基于 STM32 的电机控制与 FOC 学习工程，用于逐步实现、验证和记录电机驱动、编码器读取及电流、速度、位置控制。

## 工程范围

后续开发的工程、源码、测试及学习笔记都放在本仓库目录内。当前仓库包含初始化文件与 AI 协作/审查规范，尚未加入可烧录的电机固件或可运行的关节仿真模型。

同级的 `../资料/` 是本地参考资料目录，不属于本仓库，不上传 GitHub。需要借鉴套件源码时，按具体学习任务引入必要文件，保留原作者说明，并核对相关许可。

## 开发与验证

1. 每个独立工程放在本仓库内的独立子目录，并提供自己的构建和接线说明。
2. 修改后先完成适用的编译或软件验证，再进行硬件测试。
3. 硬件测试记录应注明板卡、电机、供电、固件版本及观察结果。编译通过不等于硬件运行已验证。
4. 使用 Issue 记录问题，使用分支和 Pull Request 管理后续修改。

软件安装包、工具安装目录、编译中间文件及本机凭据不纳入版本控制。
